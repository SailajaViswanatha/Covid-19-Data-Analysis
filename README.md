# Covid-19 Data Analysis
In this project the goal is, to analyze Country wise 
Total Covid cases, Total Deaths, total active cases as well as Total
recovered cases and total death rate, so that the countries with high 
active cases will be provided more medical facilities.
Used Power Query to clean and transform the data. The total
no. of covid cases like new cases, active cases,recovered cases are
analyzed along with total death rate and new death rate. DAX 
functions are used to calculate total death rate and new death rate
A report is created to analyze country wise high active
cases, recovered cases and deaths so that more facilities can be 
provided to those areas
